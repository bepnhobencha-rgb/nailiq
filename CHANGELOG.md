# Changelog

All notable changes to NailIQ (project and documentation) are recorded here.

## 2026-04-25

- **Brand system lock (PROMPT #012):** Defined and locked NailIQ **brand role** (headline = focus, CTA = second, wordmark = anchor), **logo type scale** (no `text-2xl`+ on landing wordmark; mobile `text-base`–`text-lg`, desktop `text-lg`–`text-xl`), **color usage** (gold only for CTA / highlight / focus; palette fixed in tokens and `globals.css`), **calm premium feel**, and **distributed branding** (header, card `Badge`, footer “Powered by”). Updated `src/shared/theme/tokens.ts` (JSDoc), `src/components/user/MarketingHome.tsx` (wordmark, spacing, tagline cap vs headline, `footerPoweredBy`), `src/shared/i18n/user/en.ts` + `vi.ts`, **PROJECT_BRAIN.md**, **CHANGELOG.md**, **.cursorrules** (`BRAND RULES`) to prevent future UI inconsistency. No layout or page redesign.
- **SEO + AI discovery (PROMPT #010):** Global metadata in `src/app/layout.tsx` (title template and default, description, keywords, Open Graph, Twitter, robots, `metadataBase` via `getSiteUrl()`). Landing `metadata` + JSON-LD graph in `src/app/page.tsx` (`getLandingJsonLd` in `src/shared/seo/jsonLd.ts`: `SoftwareApplication`, `Organization`, `WebSite`). Semantic landing copy: `heroHeadline`, `seoIntro`, benefit list with `h2`/`h3` in `MarketingHome`; i18n keys in `src/shared/i18n/user/en.ts` and `vi.ts`. `src/app/robots.ts`, `src/app/sitemap.ts` (`/`, `/register`), `public/ai.txt`, `public/llms.txt`. Register stub `src/app/register/page.tsx`. Booking route `generateMetadata` in `src/app/[shop]/page.tsx`. Helpers `src/shared/seo/site.ts`. SEO rules appended to `.cursorrules`.
- **Language system (PROMPT #008):** Split by surface — **user UI** (foundation home) uses `src/shared/i18n/user/en.ts` + `vi.ts`, `getUserMessages`, `EN | VI` toggle (`UserLanguageToggle`), and `useUserLanguage` (persist `nailiq-user-lang` in `localStorage`, default English, `document.documentElement.lang` sync). **Booking UI** is English only: `src/shared/i18n/booking/en.ts`, `src/app/[shop]/page.tsx` stub, `BookingDocumentEn` to keep `html` `lang` English; no toggle and no user-locale on that route. `PhoneFrame` accepts optional `serviceStrip` for translated rotating labels. Files: `src/shared/i18n/user/*`, `src/shared/i18n/booking/en.ts`, `src/shared/lib/useUserLanguage.ts`, `src/components/user/MarketingHome.tsx`, `UserLanguageToggle.tsx`, `src/app/[shop]/*`, `src/app/page.tsx` → `MarketingHome`, `src/components/ui/PhoneFrame.tsx`.
- **Responsive adaptive UI (PROMPT #007):** Mobile-first `ResponsiveShell`, `MobileStack` (max width mobile column, `pb-safe` / optional `stickyCta` + `pb-safe-cta`), and `DesktopSplit` (`lg+` two columns, max `1180px`). `tokens.ts`: `breakpoints` and `layout`. `globals.css`: `--max-nq-*`, `--pad-nq-*`, `html`/`body` `overflow-x: hidden`, `pb-safe` utilities. Foundation home reflow: iPhone order logo → copy → trust → CTA → input → phone; desktop: copy column + larger headline + `PhoneFrame` with desktop gold wash. `layout.tsx` body `min-h-dvh` / `overflow-x-hidden`. Files: `src/components/layout/ResponsiveShell.tsx`, `MobileStack.tsx`, `DesktopSplit.tsx`, `src/shared/theme/tokens.ts`, `src/app/globals.css`, `src/app/page.tsx`, `src/app/layout.tsx`.
